# HTML-Cleanup
Cleans up HTML markup from LibApps WYSIWYG.

![A screenshot of Cleanup showing input and output textareas and filters for selecting rules to apply](https://github.com/NouveauReece/HTML-Cleanup/blob/main/clean-up-screenshot.png?raw=true)  

Developed to help decrease the amount it time it takes to make markup more accessible by applying some standardisation and removing unnessary markup generated by the WYSIWYG editor. Used during the process of doing accessibility remediation at Indiana University.
